# ShopLite TRD

## Overview
ShopLite is implemented as a modular monolith: React (Vite + TypeScript) frontend, FastAPI backend, SQL Server 2022 (Express for local), SQLAlchemy 2.x ORM, Alembic migrations, and PyTest backend unit tests. Backend modules are `catalog`, `cart`, `checkout`, `orders`, and `search`. API is REST/JSON only. Checkout does not process payment; it creates an order with status `PLACED`.

## Layering Rule
1. Dependency direction is strict: `router -> service -> repository -> models`.
2. `router.py`: request/response mapping, validation wiring, HTTP status codes.
3. `service.py`: business rules and orchestration only; no raw SQL, no session query construction.
4. `repository.py`: all SQLAlchemy query logic and persistence.
5. `models.py`: SQLAlchemy ORM entities only.
6. `schemas.py`: Pydantic request/response DTOs only.
7. Cross-module calls must go through the target module service, never another module repository.

## Data Model (per feature)
- Catalog:
  - `products(id PK, sku UNIQUE, name, description, price DECIMAL(10,2), category, in_stock BIT, created_at, updated_at)`.
- Cart:
  - `carts(id PK, session_id UNIQUE, created_at, updated_at)`.
  - `cart_items(id PK, cart_id FK->carts.id, product_id FK->products.id, quantity INT CHECK > 0, unit_price DECIMAL(10,2))`.
  - Unique constraint: `(cart_id, product_id)`.
- Checkout:
  - Uses current cart snapshot; validates non-empty cart and stock at placement time.
  - Creates order and order_items in one DB transaction.
- Orders:
  - `orders(id PK, session_id, status VARCHAR(20) default 'PLACED', total_amount DECIMAL(10,2), created_at)`.
  - `order_items(id PK, order_id FK->orders.id, product_id FK->products.id, product_name, quantity INT, unit_price DECIMAL(10,2), line_total DECIMAL(10,2))`.
- Search:
  - Query source is `products`; filters: `category`, `in_stock`, `min_price`, `max_price`; keyword on `name` and `description`.
  - SQLAlchemy builds parameterised predicates; pagination fixed to `limit/offset`.

## Error Format
All non-2xx responses use:
```json
{
  "error": {
    "code": "RESOURCE_NOT_FOUND",
    "message": "Product 42 not found"
  }
}
```
`code` is stable, uppercase snake case; `message` is human-readable English. Global FastAPI exception handlers map domain/infrastructure exceptions to this shape.

## Conventions
- Python files/modules: snake_case. Classes: PascalCase. Constants/env vars: UPPER_SNAKE_CASE.
- API paths are plural nouns, e.g. `/api/products`, `/api/cart/items`, `/api/orders`.
- DB table names plural snake_case; PK `id`; FK pattern `<entity>_id`.
- Monetary values use `DECIMAL(10,2)` and Python `Decimal` (not float).
- Timestamps stored in UTC.
- Environment variables:
  - `APP_ENV=development|test|production`
  - `API_HOST=0.0.0.0`
  - `API_PORT=8000`
  - `DATABASE_URL=mssql+pyodbc://<user>:<pass>@localhost\\SQLEXPRESS/shoplite?driver=ODBC+Driver+18+for+SQL+Server&TrustServerCertificate=yes`
  - `CORS_ORIGINS=http://localhost:5173`
  - `LOG_LEVEL=INFO`

## How to Run
1. Backend setup and run:
```bash
cd backend
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
alembic upgrade head
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
```
2. Frontend setup and run:
```bash
cd frontend
npm install
npm run dev
```
3. Run backend unit tests:
```bash
cd backend
pytest -q
```
